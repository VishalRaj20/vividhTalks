# Vividh Talks - Premium Podcast Platform

Vividh Talks is a cinematic, high-performance web platform designed for a modern podcasting studio. The platform features a premium dark-themed aesthetic, dynamic video content, and a seamless user experience across all devices.

## ✨ Key Features

- **Cinematic Hero Experience**: A high-impact hero carousel with smooth 12-second transitions and solid-contrast metadata overlays.
- **Dynamic Episode Library**: Full search and category-based filtering for an extensive podcast catalog.
- **Bingeable Moments**: A full-bleed horizontal scroller for "Short Clips" and highlights, perfectly aligned with the site's layout.
- **Studio-Grade UI**: A cohesive design language using **Clash Display** for headings and **JetBrains Mono** for technical metadata.
- **Glassmorphism & Depth**: Modern UI components with refined, subtler shadows and vibrant studio-grade visuals.
- **SPA Optimized**: Robust client-side routing with Vercel configuration to prevent 404s on refresh.
- **Responsive Design**: Fully optimized for mobile, tablet, and ultra-wide desktop displays.

## 🛠️ Tech Stack

- **Frontend**: React 18 with Vite for blazing fast development.
- **Styling**: Vanilla CSS with a custom design system (Variables, Flexbox, Grid).
- **Icons**: Lucide React for consistent, high-quality iconography.
- **API**: Custom hooks for YouTube Data API integration.
- **Deployment**: Configured for seamless deployment on Vercel.

## 🎨 Design System

- **Primary Accent**: `#FF4D00` (Vividh Orange)
- **Background**: `#0A0A0C` (Rich Black)
- **Typography**: 
  - Headings: `Clash Display`
  - Body: `DM Sans` / `Satoshi`
  - Metadata: `JetBrains Mono`

## 🚀 Getting Started

1. **Clone the repository**
2. **Install dependencies**: `npm install`
3. **Run development server**: `npm run dev`
4. **Build for production**: `npm run build`
